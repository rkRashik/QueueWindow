# QueueWindow

A working portfolio application for one service desk: staff issue and manage tickets, visitors privately check their place, and a public screen shows who is called. It collects no visitor personal information. Demo workspaces are isolated and disposable. Initial budget is $0; hosting target is Vercel with an external durable database. Bangladesh is the initial context; English UI and Asia/Dhaka time.

The user delegates art direction and implementation decisions. Build mobile-first, with a purpose-designed public display and printable QR tickets. Preserve accessibility, correct concurrency, and honest offline feedback. No repository push, paid resource, or deployment is authorized. Real clinic operation requires a later readiness review.
